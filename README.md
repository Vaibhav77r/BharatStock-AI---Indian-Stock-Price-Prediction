# BharatStock AI — Indian Stock Market Analytics

A polished machine-learning mini project using Python, Pandas, Scikit-learn, Plotly and Streamlit.

## Features
- Upload a CSV dataset from Kaggle
- Select date and closing-price columns
- Historical closing-price chart and optional volume chart
- Linear Regression and Random Forest comparison
- Chronological train/test split
- MAE, RMSE and R² evaluation
- Actual vs predicted chart and CSV export
- Next-observed-session estimate using the latest row

## Setup on Windows

1. Install Python 3.11 or 3.12 and VS Code.
2. Extract the project ZIP.
3. Open the extracted folder in VS Code.
4. Open Terminal > New Terminal.
5. Create a virtual environment:

   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use Command Prompt instead:

   ```bat
   py -3.11 -m venv .venv
   .venv\Scripts\activate.bat
   ```

6. Install libraries:

   ```bash
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

7. Download the assignment dataset from:
   https://www.kaggle.com/datasets/sagara9595/stock-data

8. Start the app:

   ```bash
   streamlit run app.py
   ```

9. Your browser should open the local Streamlit page. If not, open:
   http://localhost:8501

## Dataset expectations
The app attempts to detect date and closing-price columns automatically. Common names include `Date`, `Datetime`, `Close`, `Closing Price`, `Adj Close`, and `Price`. If the column names are unusual, choose the correct columns in the app.

For multiple-stock data, use the optional stock identifier filter and select one stock. If the CSV contains one stock per file, upload that file directly.
